While you work, the engine reads your textures, models and levels straight from the project folder. A game you ship reads one file instead: a pack. Making that pack is called cooking, and the tool is `scook`.

Run these from the repository folder.

<Steps>

1. **Get a project.** If you don't have one, export the demo scene as a project:

   ```bash
   dotnet run --project SpectraEngine.Executable -- d3d11 --save-project=MyGame --exit-after-save
   ```

   This writes a `MyGame` folder where you ran the command. The demo's spheres and spinning cube are built in code rather than loaded from files, so the log warns that they were saved without geometry. That is expected.

2. **Cook it.**

   ```bash
   dotnet run --project Spectra.Kitchen.CLI -- cook MyGame
   ```

   The pack lands in `MyGame/cooked` and is named after the project, here `Demo.spack`.

3. **Check the pack.**

   ```bash
   dotnet run --project Spectra.Kitchen.CLI -- verify MyGame/cooked/Demo.spack
   ```

   `verify` opens the pack on its own, with no project folder behind it, and makes sure everything a material or level refers to is really inside.

4. **Run from the pack.**

   ```bash
   dotnet run --project SpectraEngine.Executable -- d3d11 --project=MyGame --pack
   ```

</Steps>

## What cooking does

| You author | The pack holds | Why |
|---|---|---|
| `.png` textures | `.simage` | Already compressed for the graphics card, with mipmaps. |
| `.gltf` models | `.smodel` | Ready to upload, no import step. |
| `.wav` sounds | `.saudio` | Resampled to one rate. Loop points and markers are kept. |
| `.smap` levels | `.scmap` | Geometry already built, so loading does no carving. |
| `.spectramat` materials | the same text | Checked, so a missing texture fails the cook. |

A cooked texture is larger on disk than its PNG. It loads faster and takes less video memory.

## Markers in a sound

A marker is a named moment in a sound. The cook takes markers from the sound file and keeps them in the cooked sound.

Place markers in your audio editor and give each one a name. Reaper, Adobe Audition, Sound Forge and Ocenaudio can save them inside the `.wav`. In Reaper, turn on markers in the render settings. In Audition, tick "Include markers and other metadata" when you save.

Audacity does not save its labels into a `.wav`. Export the label track with its Export Labels command and save the file beside the sound, with the sound's name and `.markers.txt`:

```
Sounds/guard_hey.wav
Sounds/guard_hey.markers.txt
```

Each line of that file is a start time in seconds, a tab, an end time, a tab and the name. If you write the file by hand you can leave the end time out. The gap in each line is one tab:

```
0.5	now
1.25	door opens
```

A name that is a number needs the end time in front of it, or the cook takes it for one.

The label file is only read when the `.wav` has no markers of its own. If both have markers, the cook uses the ones in the `.wav` and warns.

A marker with no name is called `marker` and its place among the sound's markers, counted from the start. If the third marker has no name, it is `marker3`.

Four warnings are about markers:

| Code | Means |
|---|---|
| `SC4007` | A marker lies past the end of the sound. It is left out. |
| `SC4008` | A line in a `.markers.txt` file is not a marker. It is skipped. |
| `SC4009` | A `.markers.txt` file sits beside a `.wav` that has markers of its own. The file is not read. |
| `SC4010` | A marker with no name got a number that another marker already has as its name, such as `marker2`. Name it. |

## Changing a file while running from a pack

Add `--dev` and the engine lays your project folder over the pack, so a file you edit wins over the cooked one:

```bash
dotnet run --project SpectraEngine.Executable -- d3d11 --project=MyGame --pack --dev
```

## Limits today

A cooked level holds its geometry, its collision, its lights and its entities, so you can walk it: add `--play` to start on foot.

A model placed in a level is not drawn from a cooked level yet.

A [sound](/reference/sound-entities/) in a level is heard from a cooked level only. The editor does not play it yet.
