title: Keyboard and mouse
description: Every shortcut in the editor.
---

The editor shows this same list under Help, Keyboard reference.

Letter keys stand down while a camera is driving: with the right mouse button held, <kbd>W</kbd> flies forward instead of picking the move tool.

## Getting around

| Input | Does |
|---|---|
| Right-drag | Look. Hold it and use <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd>, <kbd>Q</kbd> and <kbd>E</kbd> to fly. |
| <kbd>Alt</kbd> + drag | Orbit the selection. |
| Middle-drag | Pan. |
| Wheel | Zoom toward the cursor. |
| <kbd>F</kbd> | Frame the selection. |
| <kbd>Shift</kbd> + <kbd>F</kbd> | Frame everything. |
| <kbd>F7</kbd> | Switch between the editor camera and the engine fly camera. |
| Numpad <kbd>7</kbd>, <kbd>1</kbd>, <kbd>3</kbd> | Top, front and right views, straight on with no perspective. |
| <kbd>Ctrl</kbd> + Numpad <kbd>7</kbd>, <kbd>1</kbd>, <kbd>3</kbd> | Bottom, back and left. |
| Numpad <kbd>5</kbd> | Back to perspective. Looking around or orbiting also does. |

## Selecting

| Input | Does |
|---|---|
| Click | Select what is under the cursor. |
| <kbd>Ctrl</kbd> + click | Add to or remove from the selection. |
| <kbd>Ctrl</kbd> + <kbd>A</kbd> | Select every top-level object. |
| Drag on empty space | Box select. |
| Right-click | Open the scene menu on whatever is under the cursor. |
| <kbd>Esc</kbd> | Clear the selection. |

## Building

| Input | Does |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>1</kbd> | Insert a block. |
| <kbd>Ctrl</kbd> + <kbd>2</kbd> | Insert a part. |
| <kbd>Ctrl</kbd> + <kbd>3</kbd> | Insert a cut. |
| <kbd>Ctrl</kbd> + <kbd>4</kbd> | Insert a light. |
| <kbd>Ctrl</kbd> + <kbd>D</kbd> | Duplicate the selection. |
| <kbd>Del</kbd> | Delete the selection. |
| <kbd>Ctrl</kbd> + <kbd>G</kbd> | Group the selection. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd> | Ungroup. |
| <kbd>Ctrl</kbd> + <kbd>T</kbd> | Convert the selection between block and part. |
| <kbd>F2</kbd> | Rename, with the scene tree focused. |

## Moving things

| Input | Does |
|---|---|
| <kbd>2</kbd> or <kbd>W</kbd> | Move tool. |
| <kbd>3</kbd> or <kbd>R</kbd> | Size tool. |
| <kbd>4</kbd> or <kbd>E</kbd> | Rotate tool. |
| <kbd>X</kbd> | Swap the drag axes between world and local. |
| <kbd>Y</kbd> | Swap the handles between Studio and Classic. |
| <kbd>Shift</kbd> while sizing | Use the other anchoring for one drag. |
| <kbd>G</kbd> | Snap to the grid. |
| <kbd>[</kbd> and <kbd>]</kbd> | Finer and coarser grid. |
| <kbd>Alt</kbd> while dragging | Flip snapping for that one drag. |
| <kbd>Esc</kbd> while dragging | Cancel the drag and put it back. |

## History and files

| Input | Does |
|---|---|
| <kbd>Ctrl</kbd> + <kbd>Z</kbd> | Undo. |
| <kbd>Ctrl</kbd> + <kbd>Y</kbd> | Redo. <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> does the same. |
| <kbd>Ctrl</kbd> + <kbd>S</kbd> | Save the level. |
| <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | Save as. |
| <kbd>Ctrl</kbd> + <kbd>N</kbd> | New level. |
| <kbd>Ctrl</kbd> + <kbd>O</kbd> | Open a level. |

## Looking at the world

| Input | Does |
|---|---|
| <kbd>F8</kbd> | Walk the level in first person. <kbd>F8</kbd> or <kbd>Esc</kbd> leaves. |
| <kbd>F9</kbd> | Draw the character capsule, while playing. |
| <kbd>F1</kbd> to <kbd>F5</kbd> | Wireframe, CSG vertices, bounds, face normals, node axes. |
| <kbd>F6</kbd> | Cycle the rendering pipeline. |
