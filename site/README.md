# Spectra docs site

The user docs, built with [Starlight](https://starlight.astro.build).

```bash
npm install
npm run api      # C# API reference from the engine's /// comments, needs the .NET SDK
npm run dev      # http://localhost:4321
npm run build    # static site in dist/
```

How to write pages, add images and embed video: `src/content/docs/contributing/writing-docs.mdx`.
